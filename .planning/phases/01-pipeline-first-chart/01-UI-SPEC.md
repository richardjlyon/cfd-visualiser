# Phase 1 — UI Design Contract

> Visual and interaction contract for the first public-facing page of the CfD Visualiser: an Observable Framework site hosting CHART-01 (the "scissors" strike-vs-market time series) with a shock-metric counter, editorial prose, educational tooltips, source citation, last-updated stamp, per-chart image download, and downloadable JSON. Generated by gsd-ui-researcher; verified by gsd-ui-checker.

> **Reference aesthetic:** energydashboard.co.uk/live — crisp, data-dense but legible, public-facing. Charts are the primary content; the shell is invisible.

> **shadcn gate:** NOT APPLICABLE. Stack is Observable Framework + Pico CSS (Markdown-first static site). React/Next.js/Vite are explicitly rejected by CLAUDE.md "What NOT to Use". No `components.json`, no component registry. Tremor.so and ECharts are similarly out of scope per CLAUDE.md.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Pico CSS applied classlessly, no component generator) |
| Preset | not applicable |
| Component library | none — Observable Framework renders Markdown with inline `js` cells; UI primitives come from Pico CSS element styling |
| Icon library | none in Phase 1 (no component-level iconography required; Plot renders its own SVG marks) |
| Font | Pico CSS default system stack: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Oxygen, Ubuntu, Cantarell, "Helvetica Neue", sans-serif` (zero webfont cost, mobile-optimised) |
| Theme mode | Pico CSS light theme **locked** (light-only; `data-theme="light"` on `<html>`). Dark mode auto-switch suppressed — editorial consistency preferred over system preference. Chart palette is colourblind-safe on the light surface. |
| Wordmark | "CfD Visualiser" (working title — confirmed for v1 per CLAUDE.md; revisit at v2) |

> **Theme change from baseline:** Dark mode auto (`prefers-color-scheme`) is replaced by locked light-only. The energydashboard.co.uk reference aesthetic uses a consistent light surface. This is recorded as a resolved discretion from the Open Confirmations.

## Spacing Scale

8-point scale (multiples of 4). Pico CSS's default rhythm already uses rem-based spacing compatible with this grid; these tokens pin the exact values for chart-specific CSS.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gaps (e.g. tooltip padding), icon-text gaps |
| sm | 8px | Compact element spacing (caption-to-source gap) |
| md | 16px | Default element spacing; chart-to-caption gap; paragraph rhythm (Pico default `1rem`) |
| lg | 24px | Section padding inside boxouts; chart-to-boxout gap |
| xl | 32px | Chart-to-next-section gap; header-to-main gap |
| 2xl | 48px | Major section breaks (between chart stack and footer) |
| 3xl | 64px | Page-level top/bottom padding on desktop |

**Exceptions:**
- Minimum tap target: 44×44px (WCAG 2.5.5 AAA, required by OPS-03). Applies to round-toggle controls, download-image button, and download-JSON link. 44 is not on the 8-point grid; it is an accessibility override.
- Shock counter numeral height: approximately 80px on desktop / 48px on mobile — an intentional typographic exception for maximum visual impact. Implemented via inline CSS, not a Pico utility class.
- Content column max-width: **720px** on screens ≥768px (readable measure for prose + gives charts a natural constrained width). Pico's default container caps at ~1130px — we narrow it for this editorial layout.

## Typography

Four sizes, two weights. All sizes expressed in px but implemented as rem (Pico default root = 16px; these values resolve correctly).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / caption / source line | 16px | 400 (regular) | 1.5 |
| Chart axis labels / tooltip / boxout label / glossary tooltip | 14px | 400 (regular) | 1.4 |
| Chart title / h2 | 20px | 600 (semibold) | 1.3 |
| Page title / h1 | 28px | 600 (semibold) | 1.2 |

**Shock counter typography (additional rule — does not add a fifth size):**
- The counter numeral and its currency prefix are a display element, not body text. Size: `clamp(48px, 8vw, 80px)` — CSS fluid value, not a discrete token. Weight: 600 (semibold — same weight token as h1). Letter-spacing: `-0.02em` for tabular mono feel.
- The counter label line beneath ("Total CfD subsidy paid since 1 Jan {year}") uses the standard 16px/400 body role.

**Rules:**
- No more than 4 discrete sizes, no more than 2 weights site-wide in Phase 1. The shock counter uses a fluid expression of the existing semibold weight — it is not an additional weight.
- Pico default `small` (≈0.875rem = 14px) is reused for the source-citation line — no override needed.
- Chart tick labels use 14px; chart axis titles use 14px semibold. Plot's default 10px tick size is **overridden** via `fontSize: 14`.
- Italics reserved for the source-citation line only (matches editorial convention).
- Glossary tooltip body text uses 14px/400 (same role as axis labels) — visually subordinate to chart content.

## Color

Dominant / secondary / accent split. Palette is **Okabe-Ito colourblind-safe** (required by OPS-03). Light theme is locked (no dark-mode variant needed post decision above). All contrast values are verified against `#ffffff` surface.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` | Page background, chart plot area |
| Secondary (30%) | `#f1f3f5` (Pico `--pico-muted-bg`) | "What does this mean?" boxout; footer; glossary tooltip background; shock counter surround band |
| Accent (10%) | `#0072B2` (Okabe-Ito blue) | **Strike price line only**, links, Download JSON link, Download Image button border |
| Shock counter numeral | `#0072B2` (same accent) | The cumulative cost figure — uses accent to signal "the number that matters" |
| Data: market reference price | `#E69F00` (Okabe-Ito orange) | Market reference price line |
| Data: subsidy gap fill | `#D55E00` (Okabe-Ito vermillion) at 18% opacity | Area fill between strike and market lines when strike > market (positive subsidy) |
| Data: clawback fill | `#009E73` (Okabe-Ito green) at 18% opacity | Area fill when market > strike (negative subsidy / 2022 clawback) |
| Neutral gridline | `#dddddd` | Chart gridlines, axis ticks |
| Text primary | `#212121` (Pico default light) | Body copy |
| Text muted | Pico `--pico-muted-color` | Source line, last-updated stamp, axis tick labels, glossary tooltip dismiss hint |
| Glossary tooltip border | `#dddddd` (neutral gridline token) | 1px border on tooltip popover |
| Destructive | not used in Phase 1 | No destructive actions exist (view-only page) |

**Accent reserved for:**
1. The strike-price line in CHART-01 (the "what consumers are locked into" signal)
2. The shock counter numeral
3. Hyperlinks in prose (Pico default behaviour)
4. The "Download JSON" link
5. The "Download Image" button border/icon
6. Focus ring on interactive controls (keyboard accessibility, Pico default)

**Explicitly NOT accent-coloured:** round-toggle buttons (neutral border in default state; accent fill in active state), caption text, source line, boxout heading, glossary tooltip background. Accent must remain rare to retain signal value.

**Colour-only encoding is FORBIDDEN** (OPS-03). The subsidy gap is communicated by:
1. The two-line geometry (always visible)
2. The fill colour (vermillion vs green)
3. Direct tooltip readout: "Subsidy: £X/MWh" with explicit sign

## Shock Metric Counter

A prominent cumulative-cost display at the top of the landing page, inspired by the debt-clock genre. On a static site rebuilt daily, this is a **build-time static figure**, not a live JS ticker. The number shown is the total CfD subsidy paid from 1 January of the current year to the most recent settlement date in the dataset.

| Property | Specification |
|----------|--------------|
| Position | First visible element below the page header; above the chart section |
| Layout | Full-width band with `background: var(--pico-muted-bg)` (#f1f3f5). Centred content. Vertical padding: 32px (xl token) top/bottom on desktop; 24px (lg) on mobile |
| Counter label (above numeral) | `Total CfD subsidy paid since 1 Jan {build_year}` — 16px/400, text-muted colour |
| Counter numeral | Formatted as `£X.XX billion` — see numeric format below. Size: `clamp(48px, 8vw, 80px)`, weight 600, colour `#0072B2` (accent) |
| Precision | Two decimal places of billions (e.g. `£3.47 billion`). Do not display raw millions — the billion framing provides the "shock" impact |
| Separator | Comma thousands separator on the underlying figure in the Python artefact, but displayed at billions precision the comma is not visible. Store raw figure as `{ "ytd_subsidy_gbp": 3470000000, "ytd_subsidy_bn_formatted": "£3.47 billion", "ytd_label_year": 2026, "ytd_as_of": "2026-03-30" }` |
| "As of" stamp (below numeral) | `As of {settlement_date}` — 14px/400, text-muted colour. Prevents confusion about the figure being live |
| Comparison line (optional in Phase 1) | `That's equivalent to approx. {N} average UK household energy bills.` — 16px/400. Household bill constant defined in `pipeline/units.py` as `ANNUAL_HOUSEHOLD_ENERGY_BILL_GBP = 1_568` (Ofgem price cap Q1 2025 baseline; update annually). Only render this line if the constant is defined and non-zero |
| Responsive | Full-width band at all breakpoints. Numeral `clamp` ensures legibility from 320px wide. No horizontal scroll |
| Data source | Emitted by `src/data/meta.json.py` alongside the existing `last_updated` field |
| Update cadence | Rebuilt daily — the number changes at each successful pipeline run. It is explicitly NOT a live JS counter. The "As of" stamp makes this unambiguous |

## Comparative / Overlay Pattern

For charts where a household-bill context line is meaningful (CHART-01 in Phase 1 has this as an optional overlay; CHART-02 and CHART-03 in Phase 2 will use it more extensively):

| Property | Specification |
|----------|--------------|
| Background reference | Dashed horizontal or area band showing the Ofgem price-cap baseline (£/MWh equivalent, derived from `ANNUAL_HOUSEHOLD_HOUSEHOLD_ENERGY_BILL_GBP / avg_household_kwh_per_year × 1000`). Colour: `#888888` at 40% opacity — neutral, clearly subordinate to the data series |
| Foreground data | Primary data series (strike price, market price) rendered at full opacity above the reference band |
| Reference label | Short inline text label at the right edge of the band: `Avg. household rate (Ofgem)` — 14px/400/text-muted |
| Tooltip behaviour | The reference band does NOT generate its own tooltip row. If the user hovers near the band, the existing tooltip (strike/market/subsidy) is shown. A prose note below the chart explains the reference |
| Phase 1 decision | This overlay is **optional in Phase 1** — the chart builder should stub the constant but the overlay is only rendered if `SHOW_HOUSEHOLD_REFERENCE_OVERLAY = True` in the build config. Default: `False` for Phase 1 |

## Educational Tooltips (Glossary Terms)

Hover/tap affordances for jargon terms used in captions, boxouts, and axis labels. Glossary strings are stored in `src/content/glossary.json` (already in the Assets Inventory). This component is implemented as a lightweight plain-JS inline snippet — no React, no Tremor.

| Property | Specification |
|----------|--------------|
| Trigger element | `<abbr data-glossary="cfd">CfD</abbr>` pattern — standard HTML `<abbr>` element with a `data-glossary` key attribute. Pico CSS renders `abbr` with a dotted underline by default — this is the affordance |
| Desktop trigger | Hover (`mouseenter`) — tooltip appears after 150ms delay (prevents accidental triggers while scanning text) |
| Mobile trigger | Tap (`touchstart`) on the `<abbr>` element |
| Dismiss (desktop) | `mouseleave` from the `<abbr>` — tooltip disappears after 100ms delay (prevents flicker when moving to the tooltip itself) |
| Dismiss (mobile) | Tap anywhere outside the tooltip, or tap the `<abbr>` again |
| Dismiss (keyboard) | `Escape` key dismisses the active tooltip |
| Keyboard focus | `<abbr>` elements receive focus via Tab. `Enter` or `Space` opens the tooltip. This makes the glossary keyboard-accessible without additional ARIA trickery |
| Tooltip appearance | Floating `<div role="tooltip">` positioned above the `<abbr>` (CSS `position: absolute`; falls back below on scroll overflow). Background: `#f1f3f5` (secondary). Border: 1px solid `#dddddd`. Border-radius: 4px. Padding: 8px 12px (sm/md tokens). Box-shadow: `0 2px 8px rgba(0,0,0,0.12)`. Max-width: 280px |
| Tooltip content | Term name in 14px/600 semibold, followed by one-line definition in 14px/400. Example: **CfD** — "Contract for Difference — a government scheme that guarantees renewable generators a fixed price per MWh." |
| Animation | `opacity` fade-in over 120ms — no slide. `prefers-reduced-motion` media query disables the fade |
| ARIA | Tooltip `<div>` has `role="tooltip"` and `id="tooltip-{key}"`. The `<abbr>` has `aria-describedby="tooltip-{key}"` when the tooltip is visible |
| Z-index | 100 — above chart SVG (Plot uses `z-index: 0` on the SVG container by default) |
| Phase 1 glossary keys | `cfd`, `strike_price`, `reference_price`, `imrp`, `allocation_round`, `intermittent`, `dispatchable` |
| Implementation | Inline `<script>` in `src/index.md` (≈60 lines of vanilla JS). No npm dependency. The script reads `glossary.json` at page load (fetched from `/data/glossary.json` — Framework copies `src/content/glossary.json` to `dist/data/` if registered as a static file) |

**Glossary entries for Phase 1** (stored in `src/content/glossary.json`):

| Key | Term | One-line gloss |
|-----|------|----------------|
| `cfd` | CfD | Contract for Difference — a government scheme that guarantees renewable generators a fixed price per MWh. |
| `strike_price` | Strike price | The guaranteed £/MWh a generator is paid under its CfD. |
| `reference_price` | Reference price | The market price the CfD is measured against. |
| `imrp` | IMRP | Intermittent Market Reference Price — the wholesale benchmark used for wind and solar. |
| `allocation_round` | Allocation round | A government auction round in which CfDs were awarded. |
| `intermittent` | Intermittent | Generators (wind, solar) whose output depends on weather and cannot be scheduled. |
| `dispatchable` | Dispatchable | Generators (biomass, hydro) whose output can be scheduled on demand. |

## Per-Chart "Download Image" Button

A "Download Image" affordance on every chart figure, generating a 1200×630 social-ready PNG with branding, current data point, and source citation. For Phase 1, this covers CHART-01 only.

**Generation approach:** The PNG is pre-generated at build time by matplotlib (same path as the existing OG card). It is served as a static file; the button is a plain `<a download>` link. No JS canvas export, no client-side rendering.

| Property | Specification |
|----------|--------------|
| Button label | `Download image` — no emoji, no icon in Phase 1 |
| Button placement | Immediately below the chart figure, left-aligned with the chart caption. Spacing above: 8px (sm token). Rendered as a `<small>` block containing the `<a>` — visually subordinate to the Download JSON link, which is more useful for analysts |
| Button element | `<a href="/assets/charts/chart-3c.png" download="cfd-scissors-{build_date}.png">Download image</a>` — plain anchor, no JS |
| Filename convention | `cfd-{chart-slug}-{YYYY-MM-DD}.png` — e.g. `cfd-scissors-2026-04-15.png`. The date is the pipeline build date baked into the filename at build time via a Framework string interpolation in the `href` |
| Touch target | The `<a>` is wrapped in a `<p style="min-height:44px; display:flex; align-items:center;">` to meet the 44px tap target requirement |
| Dimensions | 1200 × 630 (Open Graph standard; also correct for Twitter/X card and LinkedIn post) |
| Background | `#ffffff` |
| Content regions | Top-left: wordmark "CfD Visualiser" in 18px DejaVu Sans Bold. Top-right: build date in 14px. Chart body: simplified CHART-01 scissors (two lines + area fill, no toggles, no interactive tooltip) — same Okabe-Ito palette. Bottom-left: one-line takeaway text (same as EDIT-01 caption, ≤100 chars). Bottom-right: source citation "Source: LCCC ACGE dataset · dp.lowcarboncontracts.uk" in 12px |
| Branding band | 4px top border in `#0072B2` (accent) — subtle but consistent with the live chart's accent usage |
| Output path | `src/assets/charts/chart-3c.png` (generated by `pipeline/build_site_artefacts.py` at build time; Framework copies to `dist/assets/charts/`) |
| matplotlib script | Extend `plot_cfd_cost.py` or create `pipeline/export_chart_images.py` — reads the chart-3c view-model JSON, renders the simplified scissors with the content regions above, saves PNG. Called from `pipeline/__main__.py` after the view-model is built |
| Phase 1 scope | CHART-01 only. The OG site-wide card (`dist/assets/og-card.png`) remains separate and continues to be generated as before. This per-chart image is a distinct artefact |
