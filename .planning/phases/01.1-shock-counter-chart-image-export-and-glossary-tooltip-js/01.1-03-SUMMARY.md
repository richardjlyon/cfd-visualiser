## Decisions Made

- **Year source:** `int(max_date[:4])` rather than `datetime.now(UTC).year`. Reason: keeps backdated test fixtures deterministic and satisfies `test_ytd_year_from_data`; also closes the stale-data deception surface (T-01.1-02).
- **Clamp location:** SQL-level `GREATEST(..., 0.0)`, not a Python `max(x, 0)`. Reason: single source of truth, survives any future refactor that might skip the Python wrapper; additional `or 0.0` guards `None` only (empty result set).
- **Emission precision:** `round(rate, 2)`. Reason: the client counter never recomputes or re-rounds — the pre-baked constant must be final.
- **`ytd_as_of` shape:** plain `"YYYY-MM-DD"` string (same shape as `max_settlement_date`). The equality test asserts identity to `max_settlement_date`, distinguishing it from `last_updated` (ISO timestamp).
