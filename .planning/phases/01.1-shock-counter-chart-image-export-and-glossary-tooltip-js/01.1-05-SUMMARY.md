# Phase 01.1 Plan 05: Per-Chart PNG Export Summary

Ship a dark-themed `pipeline/export_chart_images.py` that renders one real scissors PNG plus three placeholders per daily build, wired into `pipeline/__main__.py` as Step 5b with a dedicated exit code and structural schema-drift retention.

## What Landed

### pipeline/export_chart_images.py (new)
- `build_scissors(chart_json, out, build_date, caption) -> Path` — 1200×630 dark-theme render of the generation-weighted monthly strike/market means, with subsidy/clawback fills, accent & orange lines, dark legend, CfD Visualiser wordmark / build-date / caption / source branding, and a 4px accent band on the **bottom** edge (see Deviations below).
- `build_placeholder(slug, label, out, build_date) -> Path` — 1200×630 "Chart coming in Phase 02" card with the chart label under it; same branding pattern.
- `build_all(out_dir, *, chart_json=None, build_date=None, captions=None) -> list[Path]` — entry point that writes all 4 PNGs. Each kwarg defaults to a sensible repo path (`src/data/chart-3c.json`, `src/data/meta.json` max_settlement_date, `src/content/captions.json`) so tests can pass just an `out_dir`.
- Dark palette constants at module top (`BG #0d1117`, `ACCENT #58a6ff`, `ORANGE #e6a817`, `SUBSIDY #f44336`, `CLAWBACK #4caf50`, `TEXT #e6edf3`, `MUTED #8b949e`, `GRID #21262d`, `CARD #161b22`). Matplotlib forced to the `Agg` headless backend.

### pipeline/__main__.py (modified)
- New `EXIT_IMAGE_EXPORT_FAILED = 8` alongside existing exit codes; docstring table extended.
- New import `from pipeline.export_chart_images import build_all as build_chart_images`.
- New **Step 5b** inserted between the existing Step 5 (OG card) and Step 6 (healthcheck ping). Reads `PIPELINE_CHART_ASSETS_DIR` (default `src/assets/charts`), loads captions.json + meta.json, calls `build_chart_images(...)` inside a try/except that returns `EXIT_IMAGE_EXPORT_FAILED` without raising.
- Schema-drift retention is structural: EXIT_SCHEMA_DRIFT returns at Step 2, so Step 5b is unreachable on drift and previous PNGs on disk survive byte-for-byte.

## Deviations from Plan

### Minor — accent-band placement locked at figure bottom
The plan's `<action>` block flagged the pixel-(0,0) conflict between the RESEARCH §Pattern 5 "accent band at top" and the `test_dark_bg` sampler, and explicitly asked the executor to move the band to the bottom (option 1). Implemented as directed; documented with a rationale comment in `_draw_branding` so future maintainers understand why the band isn't on top.

### Rule 2 (correctness) — `fig.patch.set_facecolor(BG)` on placeholder
Added an explicit `fig.patch.set_facecolor(BG)` call on the placeholder figure in addition to `facecolor=BG` on `plt.figure(...)` and `fig.savefig(...)`. Matplotlib renders an opaque dark background reliably across all 4 outputs — caught during the test_dark_bg verification where a late-binding figure patch could otherwise show a stray lighter pixel at (0,0) depending on matplotlib version. Defensive only; no behaviour change on the currently-pinned matplotlib 3.10.8.

### Rule 3 (blocking) — `build_all` signature aligned to Wave-0 test
`tests/test_export_chart_images.py::built_assets` invokes `eci.build_all(out)` with a single positional arg, while the plan `<interfaces>` block specifies four positional params. Changed `build_all` to take `out_dir` positionally and accept `chart_json`, `build_date`, `captions` as keyword-only kwargs (each with a repo-default lookup). The pipeline orchestrator passes all four explicitly. Both test contracts satisfied without modifying either RED test. Documented in the module docstring.

No auth gates. No architectural changes.

## Mitigations Applied

| Threat ID  | Mitigation |
| ---------- | ---------- |
| T-01.1-04  | Structural: EXIT_SCHEMA_DRIFT at Step 2 returns before Step 5b; pre-seeded PNGs survive byte-for-byte. Covered by `test_schema_drift_skips_png_export`. |
| T-01.1-11  | Step 5b wraps `build_chart_images` in try/except → `EXIT_IMAGE_EXPORT_FAILED`. PNG failure cannot cascade into healthcheck or block the data store. |
| T-01.1-12  | `_draw_branding` clips caption to 100 chars; matplotlib renders strings as glyphs (no HTML/markup interpretation). |
