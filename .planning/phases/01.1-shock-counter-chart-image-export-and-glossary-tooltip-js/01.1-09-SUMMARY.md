## Smoke/build adjustments committed (f1db1c7)

Two runtime bugs surfaced during the first real build:

1. **`chart-3c.png` download 404** — scissors.md's `<a href="/assets/charts/chart-3c.png">` is a raw HTML link (not a FileAttachment), so Framework does not copy the file into `dist/`. Users clicking "Download image" would 404.
2. **`glossary.json` fetch 404** — `glossary-tooltip.js` fetches `/content/glossary.json`, which Framework similarly does not copy.

Fix: added a `build:static` npm step that copies both files to their expected non-hashed paths after `observable build`:

```
"build:static": "mkdir -p dist/content dist/assets/charts && cp src/content/glossary.json dist/content/glossary.json && cp src/assets/charts/chart-3c.png dist/assets/charts/chart-3c.png"
```

Smoke script updated to accept Framework's hashed `_file/assets/charts/*.png` and `_file/assets/tailwind.*.css` paths for FileAttachment-resolved placeholder PNGs and Tailwind bundle (these are reached by users via hashed URLs, so the smoke test should check reality rather than pre-Framework assumptions).

### Reference-alignment redesign loop (commits 7b5b489 → ceb4c12)

The first pass at the dashboard chrome diverged visually from the
energydashboard.co.uk/live reference. After several user-prompted iterations
the stylesheet was rebuilt against computed-style measurements probed
directly from the live reference page (1440×900 viewport):

- palette: bg `#030712`, card `#1c202a`, nav `#10141e`, accent `#38bdf8`
  (sky-400), text `#cbd5e1` (slate-300), border `rgba(slate-300,0.10)`,
  divider `0.40`
- typography: Poppins 700 / 24px / 32px line-height for the
  `.offset-heading` hero title (with 8px sky-400 left bar + 16px padding-left,
  no shading or background); Poppins 500 / 16px for nav links and brand
- layout: `.topnav-inner` and `.page-container` capped at 1280px max-width
  with `mx-auto`, mirroring the reference's contained `.container`
- card grid: `flex flex-wrap` (not CSS grid) with `flex 1 1 360px` and 12px
  margin per card, yielding the same ~24px gutter as the reference
- cards: bg `#1c202a`, border 1px slate/10, radius 4px, padding 12px;
  centered title weight 600/16px with `border-bottom 1px slate/40` underline
- share cluster: real brand SVG icons (LinkedIn / X / Bluesky / Facebook /
  WhatsApp / email / copy) at 36×36, padding 8px, radius 8px, tinted to
  brand colour on hover
- topnav: 64px tall, brand+icon-link rows in Poppins, "Live" item carries a
  pulsing sky-400 dot, "More ▾" + sun-toggle right cluster
- shock-counter (REQ-SHOCK-01..03) folded into a slim live-ticker bar that
  sits between the hero lead and the chart grid (preserves the requirement
  without dominating the hero)
