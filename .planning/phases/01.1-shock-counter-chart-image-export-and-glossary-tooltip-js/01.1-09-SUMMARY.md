## Smoke/build adjustments committed (f1db1c7)

Two runtime bugs surfaced during the first real build:

1. **`chart-3c.png` download 404** — scissors.md's `<a href="/assets/charts/chart-3c.png">` is a raw HTML link (not a FileAttachment), so Framework does not copy the file into `dist/`. Users clicking "Download image" would 404.
2. **`glossary.json` fetch 404** — `glossary-tooltip.js` fetches `/content/glossary.json`, which Framework similarly does not copy.

Fix: added a `build:static` npm step that copies both files to their expected non-hashed paths after `observable build`:

```
"build:static": "mkdir -p dist/content dist/assets/charts && cp src/content/glossary.json dist/content/glossary.json && cp src/assets/charts/chart-3c.png dist/assets/charts/chart-3c.png"
```

Smoke script updated to accept Framework's hashed `_file/assets/charts/*.png` and `_file/assets/tailwind.*.css` paths for FileAttachment-resolved placeholder PNGs and Tailwind bundle (these are reached by users via hashed URLs, so the smoke test should check reality rather than pre-Framework assumptions).
