# Phase 01.1 Plan 07: Landing + scissors page shell Summary

**One-liner:** Rewrote `src/index.md` (dark dashboard: hero shock counter + 2×2 card grid + footer) and re-skinned `src/charts/scissors.md` (Tailwind shell + dark-theme Plot palette + Download Image anchor + 5 glossary `<abbr>` tags); preserved all scissors data-loader wiring verbatim.

## What Changed

### `src/index.md` (full rewrite)
- Header nav band with wordmark linking to `/`.
- Hero section rendered via `display(html\`...\`)` so Framework JS interpolation populates `#shock-numeral` with `data-ytd="${meta.ytd_subsidy_gbp}"` and `data-rate="${meta.gbp_per_sec_rate}"`. `aria-live="off"` on the numeral; static "As of ${meta.ytd_as_of}" stamp below.
- Label text is `"Total CfD subsidy paid since 1 Jan ${meta.ytd_label_year}"` — year derived from data, not wall-clock (mitigates T-01.1-02).
- Card grid: `grid grid-cols-1 sm:grid-cols-2 gap-6` with 4 `<a class="card">` tiles. Each tile wires `${captions["chart-<slug>"].card_title}` + `.card_hook` into title/hook fields. Card hrefs: `./charts/{scissors,co2-avoided,cumulative-subsidy,generation-heatmap}` — matches observablehq.config.js pages array (not the stale `daily-generation` stub slug).
- Footer with source link + `${meta.last_updated}` build stamp.
- Loads `/client/shock-counter.js` and `/client/glossary-tooltip.js` as ES modules.

### `src/charts/scissors.md` (page shell rewrite, data wiring preserved)
- **Preserved verbatim**: FileAttachment loader cell (chart-3c.json, meta.json, captions.json, chartDataUrl), round-toggle `Inputs.radio`, `rollupAllRounds` + `filtered` computation, `<figure role="img" aria-labelledby aria-describedby>` wrapper with hidden title div and `<figcaption>`.
- **Re-skinned Plot**: Okabe-Ito CSS variables replaced with literal hex — strike `#58a6ff`, market `#e6a817`, subsidy area `#f44336`@0.20, clawback area `#4caf50`@0.20. `style: { color: "#e6edf3", background: "#0d1117", fontSize: "14px" }` added to Plot spec. `Plot.ruleY([0])` given `stroke: "#21262d"` for dark gridline.
- **New**: `← All charts` breadcrumb, `<main class="max-w-3xl mx-auto">` content column, intro paragraph with 5 `<abbr data-glossary>` spans (cfd, strike_price, reference_price, imrp, allocation_round) above the chart, Download Image anchor pointing to `/assets/charts/chart-3c.png` with dated filename `cfd-scissors-${meta.max_settlement_date}.png`, both download anchors `min-h-[44px] inline-flex items-center`. Boxout `<aside>` rewritten with Tailwind utility classes.
