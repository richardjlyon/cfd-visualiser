## Deviations from plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking] `pytest.importorskip` at module level would hide `test_module_file_exists`**

- **Found during:** Task 1 verification (`pytest tests/test_export_chart_images.py -v` reported `collected 0 items / 1 skipped`).
- **Issue:** The plan's action block used `pytest.importorskip(..., allow_module_level=True)` which causes pytest to skip the *entire* module, including the deliberate `test_module_file_exists` guard that must RED-fail at Wave-0.
- **Fix:** Replaced the module-level `importorskip` with a deferred `_eci()` helper that calls `pytest.skip(...)` lazily inside each parametrised test. `test_module_file_exists` remains at module scope and is collected + executed, so it fails RED as intended. The parametrised PNG tests still skip cleanly until plan 05 creates the module.
- **Files modified:** `tests/test_export_chart_images.py`
- **Commit:** `6473765`

**2. [Rule 2 — Robustness] Smoke script `glossary.json` presence check handles hashed path**

- **Found during:** Task 2 drafting.
- **Issue:** Framework 1.x writes `FileAttachment` assets with a content hash under `dist/_file/content/glossary.*.json`. The plan pattern only tested the unhashed `_file/content/glossary.json` path.
- **Fix:** Added a third `find`-based fallback that accepts any `glossary.*.json` under `dist/_file/content/` so the smoke check doesn't false-FAIL post-build in plan 09.
- **Files modified:** `tests/post_build_smoke.sh`
- **Commit:** `4c19e92`

No architectural deviations (no Rule 4 checkpoint needed).
