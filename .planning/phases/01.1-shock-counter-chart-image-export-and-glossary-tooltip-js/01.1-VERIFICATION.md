## Scope Deltas (user-accepted)

### Delta 1 — Landing grid cardinality (3 cards + ticker + topnav, not 4 cards)

**Goal wording:** "a 4-card landing grid linking to detail pages for all 4 v1 charts".

**Actual shape:** `src/index.md` renders a 3-card `.chart-grid` (Scissors, Cumulative, £/tCO₂). The 4th chart (Generation heatmap / CHART-04) is linked from two other landing-page surfaces on the same view: the slim `.ticker` bar (`<a class="ticker-link" href="./charts/generation-heatmap">`) and the topnav in `observablehq.config.js` (Heatmap tab, visible on every page). All 4 detail routes are reachable from the landing page with a single click.

**Rationale / evidence:** Recorded in `01.1-09-SUMMARY.md` §"Reference-alignment redesign loop" — during Wave-4 the layout was re-tuned against a live reference (energydashboard.co.uk/live) probed via Chrome DevTools MCP. The shock counter was folded into the live-ticker bar (preserving REQ-SHOCK-01..03), and the 4th chart link migrated into that ticker row plus the topnav rather than a 4th card. User approved the final visual state.

**Intent preservation:** The goal's *purpose* — "visitor can navigate from landing to any of the 4 v1 charts" — is fully satisfied. The literal 4-card requirement is the only deviation.

### Delta 2 — Dark-theme palette re-tuned against reference

**Goal wording:** "redesigned dark-themed dashboard".

**Actual shape:** The dark palette in `src/styles/app.css @theme` (`--color-dashboard: #030712`, `--color-card: #1c202a`, `--color-nav: #10141e`, `--color-accent: #38bdf8`) differs from the CTX/UI-SPEC nominal palette (`#0d1117` / `#161b22` / `#58a6ff`). The scissors Plot inline style still uses the nominal `#0d1117` bg and `#58a6ff` accent — so the PNG export and the interactive Plot visually match each other but are a touch darker than the surrounding Tailwind chrome.

**Rationale / evidence:** Recorded in `01.1-09-SUMMARY.md` §"Reference-alignment redesign loop" — palette captured from live reference via Chrome DevTools computed styles. User approved side-by-side.

**Intent preservation:** "Dark-themed" is fully intact; only specific hex values drifted from the UI-SPEC nominal to user-approved reference values.
