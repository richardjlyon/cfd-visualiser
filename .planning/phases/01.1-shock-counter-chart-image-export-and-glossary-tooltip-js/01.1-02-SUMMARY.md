## Deviations from Plan

### Auto-fixed issues

**1. [Rule 3 — Blocking] Worktree package-lock.json was stale**
- **Found during:** Task 1 after `npm install --silent` reported "up to date" but devDependencies were absent
- **Issue:** The worktree inherited a `package-lock.json` from the main branch that had no devDependencies field, so npm did not install the new Tailwind packages despite the correct `package.json`.
- **Fix:** Removed `package-lock.json` and `node_modules/` in the worktree, then ran `npm install` to regenerate the lockfile from the current `package.json`. Binary resolved afterwards.
- **Files modified:** `package-lock.json` (regenerated)
- **Commit:** `a830f6b` (Task 1, includes regenerated lockfile)

**2. [Rule 3 — Blocking] npm install mutated package.json (added carets, dropped scripts)**
- **Found during:** Task 2 after `npm install --save-dev tailwindcss@4.2.2 @tailwindcss/cli@4.2.2`
- **Issue:** The explicit `--save-dev` install re-sorted `package.json` and replaced the exact-version pins (`"4.2.2"`) with carets (`"^4.2.2"`), and appears to have dropped the `scripts` edits made earlier in the session. The STRIDE T-01.1-06 mitigation requires exact pins.
- **Fix:** Rewrote `package.json` via shell heredoc to the plan-specified shape (exact pins, correct scripts, engines block) and amended the Task 1 commit so the correct content is what lands on disk.
- **Files modified:** `package.json`
- **Commit:** `a830f6b` (amended Task 1)
