> Visual and interaction contract for the Phase 01.1 full visual redesign: dark-theme dashboard matching energydashboard.co.uk/live aesthetic, landing page card grid, animated shock counter, per-chart PNG download, and glossary tooltip JS. Generated by gsd-ui-researcher.

> **Parent spec superseded:** Phase 01 UI-SPEC (`01-UI-SPEC.md`) Pico CSS tokens, light theme, and Okabe-Ito-on-white palette are **replaced** by this document for landing and detail pages. Still-canonical from Phase 01 spec: glossary tooltip interaction contract, ARIA contract, EDIT-05 factual-only grammar rule, and the download-image anchor pattern — all carried forward here.

## Spacing Scale

8-point scale (multiples of 4). Implemented as Tailwind config extensions.

| Token | px Value | Tailwind Class | Usage |
|-------|----------|----------------|-------|
| xs | 4px | `p-1` / `gap-1` | Icon gaps, inline padding, tooltip inner padding |
| sm | 8px | `p-2` / `gap-2` | Compact element spacing, caption-to-source gap |
| md | 16px | `p-4` / `gap-4` | Default element spacing, paragraph rhythm |
| lg | 24px | `p-6` / `gap-6` | Section padding inside cards and boxouts |
| xl | 32px | `p-8` / `gap-8` | Chart-to-next-section gap, hero vertical padding |
| 2xl | 48px | `p-12` / `gap-12` | Major section breaks, grid-to-footer gap |
| 3xl | 64px | `p-16` / `gap-16` | Page-level top/bottom padding on desktop |

**Exceptions:**
- Minimum tap target: 44×44px (WCAG 2.5.5 AAA, OPS-03). Applied to card click targets, download buttons. 44 is not on the 8-point grid — use `min-h-[44px] min-w-[44px]` as an explicit Tailwind override.
- Shock counter numeral height: `clamp(48px, 8vw, 80px)` — typographic exception for visual impact; not a spacing token.
- Content column max-width: **1200px** on desktop (wider than Phase 01's 720px single-column — Phase 01.1 is a full dashboard with a card grid; the 720px limit applied to single-column editorial mode and does not apply to the grid layout). Implemented via `max-w-7xl mx-auto px-4`.
- Card grid inner content: capped at natural card width; the grid governs layout, not a prose measure.

## Typography

Four sizes, two weights. All values in px; implemented as `text-{size}` Tailwind utilities plus `font-normal` / `font-semibold`.

| Role | Size | Tailwind | Weight | Line Height |
|------|------|----------|--------|-------------|
| Body / caption / source line | 16px | `text-base` | 400 `font-normal` | 1.5 `leading-relaxed` |
| Label / axis / tooltip / card hook | 14px | `text-sm` | 400 `font-normal` | 1.4 `leading-snug` |
| Card title / section heading / h2 | 20px | `text-xl` | 600 `font-semibold` | 1.3 `leading-tight` |
| Page / hero title / h1 | 28px | `text-[28px]` | 600 `font-semibold` | 1.2 `leading-tight` |

**Shock counter typography (additional fluid rule — does not add a fifth size):**
- Counter numeral: `clamp(48px, 8vw, 80px)` fluid, weight 600, letter-spacing `-0.02em`, font-variant-numeric `tabular-nums`. Implemented as inline style or a single dedicated Tailwind class `text-shock` defined in config.
- Counter label below: 16px / 400 (body role).

**Rules:**
- No more than 4 discrete sizes and 2 weights site-wide.
- Inter's `font-feature-settings: "tnum"` applied to the shock counter and all numeric data cells (tabular figures prevent layout shift during count-up animation).
- Chart tick labels: 14px (override Plot's default 10px via `style: { fontSize: "14px" }`).
- Italics reserved for source-citation lines only.

## Color

Dark theme palette. Dominant dark navy surface, secondary slightly lighter surface for cards, saturated accent colours for data. All values are design targets — executor must verify against the live energydashboard.co.uk/live source on implementation day; adjust if site inspection reveals specific hex values.

| Role | Hex | Tailwind token | Usage |
|------|-----|----------------|-------|
| Dominant — page background (60%) | `#0d1117` | `bg-dashboard` | Page background, chart plot area background |
| Secondary — card / panel surface (30%) | `#161b22` | `bg-card` | Cards, nav bar, metric panel backgrounds, glossary tooltip background |
| Surface border | `#30363d` | `border-surface` | Card borders, chart axis lines, tooltip border |
| Accent — primary (10%) | `#58a6ff` | `text-accent` / `bg-accent` | Shock counter numeral, primary interactive links, Download JSON/Image buttons, focus ring, active card border |
| Accent — data blue (strike price) | `#58a6ff` | `stroke-blue` | Strike price line in CHART-01 (same as accent — the line that matters) |
| Data — market orange | `#e6a817` | `stroke-orange` | Market reference price line |
| Data — subsidy fill | `#f44336` at 20% opacity | `fill-subsidy` | Area fill when strike > market (positive subsidy) |
| Data — clawback fill | `#4caf50` at 20% opacity | `fill-clawback` | Area fill when market > strike (2022 clawback) |
| Text primary | `#e6edf3` | `text-primary` | Body copy, headings, card titles |
| Text muted | `#8b949e` | `text-muted` | Source lines, last-updated stamps, axis tick labels, tooltip dismiss hint, placeholder card body |
| Text on accent (button label) | `#0d1117` | `text-on-accent` | Text on filled accent-colour buttons only |
| Destructive | not used in Phase 01.1 | — | No destructive actions exist |
| Neutral gridline | `#21262d` | `stroke-grid` | Chart gridlines, horizontal rules |

**Colour-only encoding is FORBIDDEN (OPS-03).** Chart data encoding is always communicated by geometry + colour + tooltip/label.

**Tailwind config extension** — add these as custom colours under `theme.extend.colors` in `tailwind.config.js`:
```js
colors: {
  dashboard: '#0d1117',
  card:       '#161b22',
  surface:    '#30363d',
  accent:     '#58a6ff',
  primary:    '#e6edf3',
  muted:      '#8b949e',
  grid:       '#21262d',
}
```

**Accent reserved for:**
1. Shock counter numeral
2. Strike price line in CHART-01
3. Hyperlinks in prose
4. "Download JSON" and "Download Image" interactive elements
5. Active/hover state on card click targets
6. Keyboard focus ring on all interactive elements
7. Active card border on hover

**Explicitly NOT accent-coloured:** card backgrounds (secondary surface), caption text, source lines, muted labels, gridlines, chart area background, placeholder card bodies.

**Colourblind safety:** The data palette on dark (blue/orange/red/green) follows Okabe-Ito hue intent but with luminance lifted for dark backgrounds. The subsidy/clawback fills use red vs green; a tooltip readout always provides the numeric value and sign so the distinction is not colour-only.

## Landing Page Layout

### Hero Shock Counter

| Property | Specification |
|----------|--------------|
| Position | First element below site nav; above card grid |
| Layout | Full-width band, `bg-card`, horizontal padding `px-8`, vertical padding `py-12` on desktop / `py-8` on mobile. Content centred with `text-center` |
| Label (above numeral) | `Total CfD subsidy paid this year` — 16px/400/`text-muted` |
| Numeral | Formatted as `£{N.NN} billion` — shock-size fluid typography, weight 600, `text-accent`, `font-variant-numeric: tabular-nums`, letter-spacing `-0.02em` |
| "As of" stamp | `As of {settlement_date}` — 14px/400/`text-muted`. Immediately below numeral |
| Comparison line | `That's roughly {N} average annual UK household energy bills.` — 16px/400/`text-primary`. Rendered only when `ANNUAL_HOUSEHOLD_ENERGY_BILL_GBP` constant is set |
| Count-up behaviour | On page load: start at build-time `ytd_subsidy_gbp` value; increment upward at `gbp_per_sec_rate` (constant emitted by pipeline into `meta.json`). Animation: vanilla JS `setInterval` or `requestAnimationFrame` updating a single `<span id="shock-numeral">`. No library |
| Rate source | `meta.json.gbp_per_sec_rate` — derived by pipeline as rolling 30-day mean daily subsidy ÷ 86400. Single float, rounded to 2 decimal places |
| Reduced motion | `prefers-reduced-motion: reduce` freezes the counter at the build-time value — the `setInterval` / `rAF` loop is not started. Numeral remains a number in DOM for screen readers |
| Screen reader | The `<span id="shock-numeral">` is `aria-live="off"` — the ticking update is decorative noise for AT. The static label + "as of" stamp provide the accessible reading |

## Glossary Tooltip Component

Carried forward from Phase 01 UI-SPEC interaction contract. Dark-theme visual update only.

| Property | Specification |
|----------|--------------|
| Trigger element | `<abbr data-glossary="cfd">CfD</abbr>` — standard HTML `<abbr>` with `data-glossary` slug key. CSS: `abbr[data-glossary] { text-decoration: underline dotted; text-decoration-color: var(--color-muted); cursor: help; }` |
| Desktop trigger | `mouseenter` — tooltip after 150ms delay |
| Mobile trigger | `touchstart` on the `<abbr>` |
| Dismiss (desktop) | `mouseleave` — tooltip after 100ms delay |
| Dismiss (mobile) | Tap outside tooltip or tap `<abbr>` again |
| Dismiss (keyboard) | `Escape` closes active tooltip |
| Keyboard focus | Tab to `<abbr>`, Enter/Space opens; `aria-describedby` wired when open |
| Tooltip appearance | Floating `<div role="tooltip">`. Background: `bg-card` (`#161b22`). Border: `1px solid #30363d`. Border-radius: `4px`. Padding: `8px 12px`. Box-shadow: `0 4px 12px rgba(0,0,0,0.5)`. Max-width: `280px`. `z-index: 100` |
| Tooltip typography | Term name: 14px/600/`text-primary`. Definition: 14px/400/`text-muted` |
| Animation | `opacity` fade-in over 120ms. Disabled under `prefers-reduced-motion: reduce` |
| ARIA | `<div role="tooltip" id="tooltip-{key}">` paired with `aria-describedby="tooltip-{key}"` on triggering `<abbr>` when visible |
| Dismiss hint | `(press Esc to close)` appended in 12px/`text-muted` on desktop; suppressed on mobile |
| Implementation | Vanilla JS inline `<script>` in Framework pages (≈60 lines). No npm dependency. Reads `glossary.json` at page load via `fetch('/data/glossary.json')` |
| Pages active | Landing page (`src/index.md`) + all 4 detail pages |
| NOT active on | Chart SVG tick labels and axis titles |

### Glossary Schema Migration (D-18)

Convert `src/content/glossary.json` from phrase keys to slug keys:

| Slug key | Term | One-line gloss |
|----------|------|----------------|
| `cfd` | CfD | Contract for Difference — a government scheme that guarantees renewable generators a fixed price per MWh. |
| `strike_price` | Strike price | The guaranteed £/MWh a generator is paid under its CfD. |
| `reference_price` | Reference price | The market price the CfD is measured against. |
| `imrp` | IMRP | Intermittent Market Reference Price — the wholesale benchmark used for wind and solar CfDs. |
| `allocation_round` | Allocation round | A government auction round in which CfDs were awarded to generators. |
| `intermittent` | Intermittent | Generators (wind, solar) whose output depends on weather and cannot be scheduled on demand. |
| `dispatchable` | Dispatchable | Generators (biomass, hydro) whose output can be turned on or off at will. |

## Interactions

| Interaction | Behaviour |
|-------------|-----------|
| Card click | Entire card is an `<a>` link to the detail page. Keyboard: Tab to card, Enter navigates. Hover: accent border. No JS required. |
| Shock counter count-up | Vanilla JS loop: `requestAnimationFrame` based; reads `ytd_subsidy_gbp` and `gbp_per_sec_rate` from DOM data attributes emitted by Framework. Starts at build-time figure; increments each frame by `(elapsed_ms / 1000) * rate`. No library. Disabled under `prefers-reduced-motion: reduce`. |
| Glossary tooltip | Hover (150ms) or tap on `<abbr data-glossary>`. Dismiss via mouseleave (100ms), tap outside, or Escape. Keyboard: Tab focus + Enter/Space open. |
| Round toggle (scissors detail page) | Observable Framework reactive cell — preserved from Phase 01 implementation. No change to behaviour. |
| Hover tooltip (chart) | Plot `tip: true` on data marks — unchanged from Phase 01. |
| Zoom/pan (chart) | Plot built-in brush/interval — unchanged from Phase 01. |
| Download JSON | Plain `<a href="..." download>` — no JS. |
| Download Image | Plain `<a href="..." download>` — no JS. |
| Focus ring | Tailwind `focus-visible:ring-2 focus-visible:ring-accent focus-visible:ring-offset-2 focus-visible:ring-offset-dashboard` on all interactive elements. Never suppressed. |
