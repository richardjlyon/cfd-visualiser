| **Full suite command** | `uv run pytest -x && node --test tests/glossary-tooltip.test.mjs tests/shock-counter.test.mjs && npm run build && bash tests/post_build_smoke.sh` |

- **After every task commit:** `uv run pytest -x` (quick — skips full build smoke)
- **After every plan wave:** Full suite command above
- **Before `/gsd-verify-work`:** Full suite must be green
- **Max feedback latency:** 90 seconds
