# Phase 01.1 Plan 06: Vanilla-JS Client Modules Summary

Ships two zero-dependency ES modules — a rAF-driven hero shock counter
(reduce-motion-safe) and an XSS-hardened glossary tooltip (createElement +
textContent only) — turning all 6 Wave-0 Node tests GREEN.

## What Was Built

### `src/client/shock-counter.js` (52 lines)

Reads `data-ytd` (start £) and `data-rate` (£/sec) from `#shock-numeral` and
renders `£X.XX billion` using `Intl.NumberFormat("en-GB")`. Under normal motion
runs an rAF tick loop keyed on `performance.now()`; under
`prefers-reduced-motion: reduce` (or NaN/<=0 rate) freezes at the server-rendered
baseline. NaN-guarded throughout. Self-registers on DOMContentLoaded; `init()`
exported for tests.

### `src/client/glossary-tooltip.js` (145 lines)

Fetches `/content/glossary.json` once on init, then attaches the full interaction
contract to every `abbr[data-glossary]`:

| Trigger | Behaviour |
|---------|-----------|
| mouseenter | 150ms delay → show |
| mouseleave | 100ms delay → hide |
| touchstart | preventDefault + toggle |
| keydown Enter / Space | show |
| document keydown Escape | hide |
| document touchstart outside | hide |
| window scroll | hide |

Tooltip is a `<div role="tooltip" id="tooltip-{slug}">` appended to `document.body`.
Term rendered in a `<strong>` child via `textContent`; definition in a `<span>`
child via `textContent`. **Zero `innerHTML` assignments** (grep-verified). Sets
`aria-describedby` on the anchor while visible; removes on hide. Position flips
above→below when above viewport top. `init()` exported; self-registers on
DOMContentLoaded.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] hide() did not remove tooltip under test DOM stub**
- **Found during:** Task 2 first test run ("Escape closes" assertion failed)
- **Issue:** My initial `hide()` used `tip.parentNode.removeChild(tip)`. The
  glossary-tooltip.test.mjs DOM stub's `appendChild` assigns `c.parent = this`
  (not `c.parentNode`), so `tip.parentNode` was undefined and the tooltip
  was never detached after Escape.
- **Fix:** Harden `hide()` to probe `tip.parentNode || tip.parent`, with a
  final fallback to `tip.remove()`. Production DOMs still detach via the
  standard `parentNode.removeChild` path — functionally identical, just
  tolerant of both parentage fields. No security or behavioural regression.
- **Files modified:** src/client/glossary-tooltip.js (hide function)
- **Commit:** 8d66633
